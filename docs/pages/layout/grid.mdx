
## API Reference

### GridView Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `style` | `StyleProp<GridViewStyle>` | - | Grid container styles with CSS Grid properties |
| `children` | `GridViewItemProps[]` | - | Grid items to be laid out |
| `initialSize` | `{width: number, height: number}` | - | Initial dimensions for SSR |
| `onLayout` | `(event: LayoutChangeEvent) => void` | - | Layout change callback |

### GridViewItem Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `style` | `StyleProp<GridViewItemStyle>` | - | Grid item styles with positioning properties |
| `children` | `ReactNode` | - | Content of the grid item |

### Grid Style Properties

| Property | Type | Description |
|----------|------|-------------|
| `gridTemplateAreas` | `string` | Named grid areas for layout |
| `gridTemplateColumns` | `string` | Defines column sizes (e.g., '1fr 2fr', '200px auto 1fr') |
| `gridTemplateRows` | `string` | Defines row sizes |
| `gridAutoColumns` | `string` | Size of auto-generated columns |
| `gridAutoRows` | `string` | Size of auto-generated rows |
| `gridAutoFlow` | `string` | How auto-placed items flow |
| `gap` | `string \| number` | Gap between all grid items |
| `rowGap` | `string \| number` | Gap between rows |
| `columnGap` | `string \| number` | Gap between columns |

### Grid Item Style Properties

| Property | Type | Description |
|----------|------|-------------|
| `gridArea` | `string` | Named area or position shorthand |
| `gridColumn` | `string` | Column position (e.g., 'span 2', '1 / 3') |
| `gridColumnStart` | `string \| number` | Starting column line |
| `gridColumnEnd` | `string \| number` | Ending column line |
| `gridRow` | `string` | Row position (e.g., 'span 2', '1 / 3') |
| `gridRowStart` | `string \| number` | Starting row line |
| `gridRowEnd` | `string \| number` | Ending row line |
